
Read a listed reference from a loaded platform skill.

Available only in the native chat pilot when platform skills are enabled. Procedural references join the task instructions; data references return labeled content. Only references listed in the pinned bundle can be read.

## Parameters

<ParamField type="string">
  Qualified platform skill ID.
</ParamField>

<ParamField type="string">
  Exact relative reference path listed by the skill.
</ParamField>
