
Discover authorized workspace skills by name, intent or paginated listing.

Available only in the native chat pilot when platform skills are enabled. Returns workspace skill names, descriptions and paths. Read the chosen SKILL.md with file tools; results retain their user-authored provenance.

## Parameters

<ParamField type="string">
  Name or lexical search up to 200 characters; empty lists all skills.
</ParamField>

<ParamField type="string">
  Opaque next\_cursor from the prior page, or omit for the first page.
</ParamField>
